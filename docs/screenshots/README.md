所以留在这里等实机截。

## 截之前

- **窗口尺寸统一**，建议 1280×800 或 1440×900，深浅色主题选一种，别混着来。
- **抹掉个人信息**：账号名、皮肤头像、真实用户名路径（`C:\Users\你的名字\…`）、服务器 IP。
  这些图是公开的。
- 实例名和模组用真实的就行，看起来才不像 demo。
- PNG，不要缩放，不要加边框和阴影（GitHub 自己会处理）。

## 放进来之后

在仓库根目录的 `README.md` 里加一节引用它们，例如：

## 界面
